ເຊື່ອມຕໍ່ Supabase (PostgreSQL)

ຖານຂໍ້ມູນຈິງ ຢູ່ຄລາວ — ໃຊ້ໄດ້ຫຼາຍເຄື່ອງພ້ອມກັນ

  1. ສ້າງ project ທີ່ supabase.com (Free tier ພຽງພໍ)
  2. ເປີດ SQL Editor → ວາງ SQL ຈາກໄຟລ໌ db/supabase-schema.sql (ຫຼື ກົດ “ຄັດລອກ SQL ສ້າງຕາຕະລາງ” ຂ້າງເທິງ) → Run
  3. ເປີດ Project Settings → API ຄັດລອກ Project URL ແລະ anon (publishable) key
  4. ວາງທັງສອງຂ້າງເທິງ ແລ້ວກົດ “ບັນທຶກ ແລະ ເຊື່ອມຕໍ່”
  5. ຖ້າມີຂໍ້ມູນຢູ່ SQLite ແລ້ວ ໃຫ້ຍ້າຍດ້ວຍ python tools/migrate_to_supabase.py (ເບິ່ງ README)

ໝາຍເຫດ: ໃຊ້ anon / publishable key ເທົ່ານັ້ນ — ຢ່າວາງ service_role key ໃນເບົາຣ໌ເຊີ. ຕາຕະລາງເປີດ RLS ແລະ ອະນຸຍາດໃຫ້ເຂົ້າເຖິງຜ່ານຟັງຊັນ apt_load / apt_save ເທົ່ານັ້ນ ດັ່ງນັ້ນຢ່າເຜີຍແຜ່ໜ້າເວັບນີ້ສູ່ສາທາລະນະ (ໃຜມີ URL + key ຈະເຂົ້າເຖິງຂໍ້ມູນໄດ້).
